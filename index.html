Standing rules

Tap each set as you finish it. Every set clean completes the lift and bumps next session's weight. The rest timer starts fresh on every tap — no need to uncheck and recheck.

Missed a lift? Hit ✗ instead of ticking sets. Three misses on the same lift triggers an automatic 10% deload — that's the system working, not failure.

Lower body override: if it feels off, that session reverts to light technique work regardless of phase.

Home days: 5–10 min, sub-fatiguing. Sore the next day means you did too much.
